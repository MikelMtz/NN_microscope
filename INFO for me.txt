RUN IN THE CLUSTER

command 'showgpus' for visualising which gpus are available

submit a job by:

addqueue -q gpuQueueYouChose -s --gpus numberGPUs --gputype SpecifyTheType -m GPUs[Free/Tot] ./yourProgram,
addqueue -q gpulong -s --gpus 1 --gputype rtx2080with12gb ./myProgram
    or
addqueue -q gpulong -s -m 4 --gpus 1 ./myProgram
    (if you don't mind which GPU you get)

I USED: addqueue -q gpulong -s --gpus 1 --gputype rtx4090with24gb ./submitjob.sh

    check run with: sacct -j 'id'
